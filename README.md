# evaluacion-reguladores-dc-dc
Repositorio con esquemas y manuales para el análisis comparativo de módulos reguladores de tensión (lineal y conmutado). Evalúa el rendimiento y relación costo-beneficio al alimentar una carga de 5 V y 1 A con un rizado menor a 50 mV. Desarrollado para el Trabajo final de electrónica industrial 2026-II
