# 🔬 Evidencias de Laboratorio

Registro experimental de las pruebas de los módulos LM317 y LM2596, realizadas a $V_{IN} = 12$ VDC e $I_{OUT} = 1$ A sobre una carga resistiva de 5 Ω.

## Contenido

| Archivo | Descripción |
|---|---|
| `lm317_montaje.*` | Fotografía del montaje experimental del regulador lineal |
| `lm317_rizado.*` | Captura del osciloscopio: rizado de salida del LM317 (14.4 mV) |
| `lm317_mediciones.*` | Lecturas de tensión y corriente de entrada y salida |
| `lm2596_montaje.*` | Fotografía del montaje experimental del regulador conmutado |
| `lm2596_rizado.*` | Captura del osciloscopio: rizado de salida del LM2596 (24 mV) |
| `lm2596_mediciones.*` | Lecturas de tensión y corriente de entrada y salida |
| `temperatura_lm317.*` / `temperatura_lm2596.*` | Evolución de la temperatura medida con termómetro infrarrojo |

## Resumen de mediciones

| Parámetro | LM317 | LM2596 |
|---|---|---|
| $P_{in}$ | 12.64 W | 6.77 W |
| $P_{out}$ | 4.84 W | 4.69 W |
| Eficiencia | 38.3 % | 69.2 % |
| Rizado | 14.4 mV | 24.0 mV |
| Temperatura de cápsula a 70 s | > 60 °C | 46.0 °C |
